# Aset lokal

`public/assets/islands.png` (1536 × 1024) dan `public/assets/kiko.png` (1254 × 1254 RGBA) adalah ilustrasi orisinal yang dihasilkan memakai tool imagegen bawaan untuk proyek ini. Kiko memiliki latar transparan. Tidak ada gambar eksternal yang dihotlink.

Prompt peta: Landscape children's storybook 2D adventure map; light turquoise ocean; orange counting-stone island upper left, mint leafy forest with books upper right, lavender puzzle hills lower left, coral cozy village lower right; tiny central lighthouse; sandy shores, dotted sailing paths; warm painted textures, clear sea for overlaid labels; no text, UI, letters, numbers, watermark.

Prompt Kiko: Full-body friendly green turtle, yellow shell details, coral explorer scarf, smiling and waving; warm children's storybook flat painted illustration; centered with margins; genuinely transparent background; no text or watermark.

Ikon UI dan benda: `lucide-react`, lisensi ISC (lihat LICENSE paket). Emoji petunjuk literasi dirender oleh font sistem perangkat. Font UI memakai font sistem lokal; tidak mengunduh font eksternal. Tidak ada aset berlisensi tertutup dari web.

Dunia **Krakatau Pintar 3D**, tiga avatar, rumah, pohon, gunung, perahu, dan koleksi dibuat langsung dengan geometry/material Three.js di `src/game/`; tidak ada model atau tekstur game pihak ketiga. `public/assets/krakatau-icon.svg` adalah ikon kompas vektor sederhana yang ditulis untuk proyek ini. Efek audio berasal dari osilator Web Audio, tanpa berkas audio eksternal. Screenshot `docs/krakatau-*.png` berasal dari pengujian browser menggunakan profil sintetis.
